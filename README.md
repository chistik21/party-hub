# PARTY HUB

Локальная вечеринка для 2–30 участников. Один телефон или компьютер ведёт игру и раздаёт сайт остальным. Для «Шпиона» нужны хотя бы трое, для «Мафии» — пятеро. В каждой комнате свой двухзначный код, включая коды с нулём в начале.

## Быстрый запуск с Android без ПК

1. Скачай **PARTY-HUB-SERVER.zip** в папку «Загрузки». В этом архиве уже есть сервер, сайт, звуки и картинки.
2. В Termux один раз установи Node.js 22 или новее и предоставь доступ к загрузкам. Для установки пакетов понадобится интернет.

```sh
pkg install nodejs-lts unzip
termux-setup-storage
```

3. Если DRAW PARTY всё ещё занимает порт 3000, заверши её командой Ctrl+C в той сессии. Через дополнительный ряд клавиш Termux нажми CTRL, затем C. Для запуска PARTY HUB выполни:

```sh
unzip -o ~/storage/downloads/PARTY-HUB-SERVER.zip -d ~/ &&
cd ~/party-hub-server &&
node server.cjs
```

4. На телефоне ведущего открой в браузере **http://127.0.0.1:3000**. Нажми «Создать вечеринку», введи имя и нажми «Продолжить».
5. Друзья подключаются к тому же Wi-Fi или к точке доступа ведущего. На их телефонах открой адрес из строки «По Wi-Fi» в Termux или отсканируй QR из комнаты. Safari на iPhone и браузер на Android используют одну ссылку. Оставь Termux запущенным на время матча.
6. Гости нажимают «Готов», затем ведущий запускает матч. Для следующего запуска достаточно:

```sh
cd ~/party-hub-server && node server.cjs
```

**Если сайт не открывается.** Проверь сначала адрес 127.0.0.1 на телефоне ведущего. Если там работает, проверь адрес на телефоне друга. Адрес 127.0.0.1 на устройстве друга ведёт на него самого. Если Android скрыл интерфейсы от Termux, возьми IPv4 ведущего из сведений о Wi-Fi. При раздаче с телефона посмотри «Шлюз» или «Маршрутизатор» в свойствах этой сети на телефоне друга. Набери `http://`, этот адрес и `:3000`. В окне QR веб-клиента можно вручную указать IPv4, если в приглашении появился localhost. Гостевая сеть или изоляция клиентов может запрещать такой доступ. Физический лимит точки доступа действует даже при свободных местах в комнате.

**Если порт занят.** Для второго сервера можно использовать `PORT=3001 node server.cjs`. Тогда добавь к IP порт 3001 и на телефоне ведущего, и у гостей.

## Обновление и данные

Заверши процесс в Termux через Ctrl+C и повтори распаковку и запуск из шага 3. Профили лежат в каталоге `~/party-hub-server/hub-profiles`, если запускать сервер из указанного каталога. Архив их не содержит. Свой путь задаёт переменная `HUB_DATA`. Для резервной копии после остановки сервера:

```sh
cd ~/party-hub-server &&
tar -czf ~/storage/downloads/party-hub-profiles.tar.gz hub-profiles
```

Профиль хранится у ведущего. Браузер сохраняет секрет подключения в данных сайта, приложение — в своих настройках. Открывай игру в том же браузере по тому же адресу. Очистка данных сайта, другой порт или режим инкогнито могут создать отдельный профиль. Результат записывается при завершении матча. Комнаты и незаконченные партии живут в памяти сервера. После краткого обрыва связи клиент автоматически возвращается на свой этап. Полностью опустевшая комната ждёт две минуты. Перезапуск процесса завершает активные комнаты.

## Как играть

| Режим | Правила |
|---|---|
| Шпион | Все знают место кроме шпиона. Задавайте вопросы вслух или в чате. Шпион пытается назвать место, остальные голосуют за подозреваемого. |
| Мафия | Ночью мафия выбирает жертву, доктор лечит, комиссар расследует. Днём город обсуждает и голосует. Ничья при голосовании оставляет обоих в игре. |
| Реакция | Ждите сигнала. Фальстарт стоит 50 очков. Сервер измеряет время ответа и вычитает половину измеренного RTT с ограничением поправки. |
| Мем-батл | Придумайте подпись к локальной иллюстрации или фотографии ведущего. Подписи перемешиваются, голосовать за свою нельзя. |
| Викторина | Выберите ответ из четырёх. В банке 334 задания по восьми категориям. 300 числовых заданий проверяются тестом по формуле. |
| Правда или ложь | После ответов появится правильный вариант и объяснение. |
| Угадай число | От 1 до 100. При одинаковой минимальной разнице очки получают все ближайшие. |
| Ассоциации | Запишите ассоциацию. За каждый совпавший ответ другого игрока получите 50 очков. |
| Кто из нас? | Выберите участника для дружеской ситуации. Итоги голосования общие, отдельные голоса скрыты. |
| Словесная битва | Вводите русские слова на заданную букву. Сервер проверяет букву, состав и повторы на всю комнату. Словарной проверки существования каждого слова нет. |
| Память | Запомните последовательность фигур, затем введите её по памяти. Длина увеличивается с номером раунда. |
| Найди отличие | Найдите особый символ в сетке из 25 ячеек. На результат влияют точность и скорость. |
| Цветовой хаос | Прочитайте задание и выберите значение слова или цвет чернил. |
| Змейка Online | Управляйте направлением стрелками на экране. На общей карте сервер рассчитывает движение, еду и столкновения. |
| Марафон | Три или пять разных мини-игр с общим счётом. Сервер учитывает число игроков при выборе следующей игры. |

В лобби можно смотреть матч, обмениваться сообщениями и реакциями, голосовать за следующий режим. Ведущий выбирает игру напрямую, принимает результат голосования или крутит колесо. При равенстве голосов можно переголосовать. Ведущий выбирает число раундов, время и исключения для колеса. Победы и история доступны в профиле. 45 достижений связаны с количеством партий в конкретных режимах, ещё пять — с победами.

## Состав поставки

- **PARTY-HUB-SERVER.zip** — готовый Node-сервер с зависимостью WebSocket в сборке и со всеми ресурсами сайта. Работает из распакованной папки.
- **PARTY-HUB-WEB.zip** — собранный статический клиент. Для отдельного хостинга распакуй в корень HTTP-сайта. В кнопке состояния соединения укажи адрес работающего сервера. Для игры по Wi-Fi проще запускать серверный архив, который раздаёт тот же сайт и WebSocket с одного адреса. Открытие index.html из файлового менеджера не запускает сервер.
- **PARTY-HUB-SOURCE.zip** — React/TypeScript, Android/Compose, Node, общие правила, подготовленные ресурсы, тесты и workflow. Распаковывай исходники в отдельную папку.
- **README.md** — эта инструкция. Лицензии включённых библиотек веб- и серверной сборок находятся в THIRD-PARTY-NOTICES.txt. Оригинальные векторные иллюстрации и WAV создаются скриптами в scripts/.

## Android и сборка APK

Нативный проект предназначен для Android 8 и новее. Compose отвечает за интерфейс, OkHttp — за клиентское соединение, NanoWSD и Rhino исполняют тот же игровой движок, что и Node. Сервис раздаёт веб-клиент из assets и показывает системное уведомление. В Android-проекте предусмотрены панель сервера, журнал, экспорт статистики, QR-сканер и поиск других Android-серверов по DNS-SD. Для Node-сервера используй QR или ручной адрес.

APK в поставке отсутствует. Android SDK и Gradle недоступны в среде подготовки этой версии. Сборка, запуск на устройстве и совместный матч нативного клиента с iPhone требуют проверки.

**Через GitHub Actions с телефона.**

1. Распакуй SOURCE. В корне своего репозитория размести его содержимое, включая скрытый каталог .github. Файл package.json должен находиться в корне.
2. Открой **Actions → Android → Run workflow**. Workflow также настроен на push. При необходимости включи Actions для своего репозитория.
3. После успешной сборки открой завершённый запуск и скачай артефакт **PARTY-HUB**. Внутри будет **PARTY-HUB.apk** с отладочной подписью. Это сборка для локальной установки. Долговременные обновления установленного приложения требуют одной и той же подписи.
4. На телефоне ведущего включи Wi-Fi или точку доступа, запусти приложение и нажми «Создать вечеринку». Для уведомления и камеры приложение или сканер запросят у Android разрешения. Друзьям с браузером достаточно QR-ссылки.

**С компьютера.** Нужны Node ≥22, JDK 17, Gradle 8.9 и Android SDK с платформой 35. В каталоге исходников:

```sh
npm ci && npm run build && npm test
cd android && gradle assembleDebug
```

Готовый файл при успешной сборке находится в android/app/build/outputs/apk/debug/app-debug.apk. Сайт и правила синхронизируются в assets командой npm run build. Для запуска Node после сборки выполни npm start из корня исходников.

## Общий протокол v1

HTTP раздаёт / и /info. Адрес WebSocket — /hub. Транспорт использует текстовые JSON-сообщения с полем v, равным 1. Первый запрос hello связывает сокет с локальным 192-битным ключом установки. Создание и вход используют enter. Сервер возвращает персональный state, профиль career или сообщение error. Ответ на игровой этап содержит epoch. Клиент не передаёт очки или выигравшую роль. Время окончания этапа until и текущее время now — миллисекунды.

core/engine.js определяет роли, фазы, допустимые действия и расчёт очков. core/wire.js отвечает за сессии, синхронизацию, задержку и ограничение сообщений. Нативный и Node-хосты загружают одни и те же файлы. Клиенты получают только свои секреты. Протокол рассчитан на доверенную локальную сеть. Стандартная поставка использует HTTP и WS. На HTTPS-странице браузер может запретить подключение к локальному ws:// из-за смешанного содержимого.

## Что проверено

- Сборка Vite и проверка TypeScript.
- Полная последовательность фаз каждого из 15 режимов в тестах с управляемыми часами.
- HTTP-ответ на главную страницу, 30 одновременных реальных WebSocket-подключений к Node, ограничение комнаты, повторное подключение, роли зрителя и переход прав ведущего.
- Два сетевых клиента прошли матч «Угадай число». Оба получили одинаковый дедлайн. После перезапуска Node вернулись история, очки и победа.
- В Chrome открыты главная и реальная комната, изменены настройки раунда, показан QR и запущено колесо. После перезагрузки сохранились тема и экономичный режим.
- Физические Android/iPhone, исполняемый Android-сервер, Safari, Firefox, Edge, запуск внутри Termux и показатели 60/120 FPS на устройствах ещё не проверены. Автотест с 30 клиентами измеряет работу сервера, пропускная способность реальной точки доступа может отличаться.
